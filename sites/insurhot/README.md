# InsurHOT 研究线索浏览站

独立 Sites 阅读界面，定位沿用 C0：什么重要、什么正在变化、什么正在诞生。此交付独立于 M0 应用整合与 G2 正式上线验收。

## 内容与功能
- 中文优先深色响应式界面；重要/变化/新生视角、领域筛选、机构与主题搜索。
- 6 条人工整理线索，来自中国网信网、EIOPA、NAIC、Coalition、Lemonade SEC 文件；Coalition 两卡同源，不算两份独立证据。
- 只展示最小资料元数据、链接和原创编辑研究问题；详情含核验清单与最强反方。没有正式已证实断言、趋势判级或产品评分。
- 原文日期与线索整理日期分离；历史资料不代表当前状态。
- 默认私有阅读预览；没有自动采集、付费模型、推送、数据库或用户数据处理。未批准任何真实费用。

## 运行与接入
静态入口 `dist/index.html`；任意静态 HTTP 服务可运行。无包依赖、构建过程或外部字体/图片请求。`app.js` 的 ITEMS 是本期人工整理数据；后续接正式公开读取层时必须沿用许可、事实级证据和撤回合同，不直接接未验收 M0 后端。

Sites 托管身份仅存在其独立源码仓库，未写入本仓。静态资源在本仓保留可移植副本。

## 验证与范围
- `node --check dist/app.js` 通过。
- HTML id 唯一、本地 CSS/JS 引用及关键交互挂载点检查通过。
- Sites 静态归档打包通过，发布状态在 PR 正文记录。
- 未运行浏览器视觉/交互验收；当前环境的静态预览路径不支持该工作流。
- 不声称完整应用 CI、G2、自动采集或断言级证据链已经完成。
